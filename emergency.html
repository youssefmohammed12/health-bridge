First Aid Instructions

🫀

CPR

1. Check responsiveness
2. Call 911
3. Push hard and fast in center of chest
4. Use AED if available

🔥

Burns

1. Cool with running water
2. Cover with sterile dressing
3. Do not apply ice
4. Seek medical attention

🩸

Bleeding

1. Apply direct pressure
2. Elevate the wound
3. Use clean cloth/bandage
4. Call 911 if severe

😤

Choking

1. Encourage coughing
2. Perform Heimlich maneuver
3. Call 911 if unable to breathe
4. Continue until help arrives
